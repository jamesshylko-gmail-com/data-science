# Домашнее задание №5

1) вычитать датасет, провести первичный анализ, сократить признаки, чтобы в дальнейшем работать с упрощенным датасетом

3) Применение optuna к выбранным 5 алгоритмам, нахождение лучших гиперпараметров и сравнение результатов с дефолтными и лучшими. Выбор победителя и итоговый отчет для него с визуализацией
