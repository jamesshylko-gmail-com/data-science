# Домашнее задание №4

## План:
1) вычитать датасет, провести первичный анализ, сократить признаки, чтобы в дальнейшем работать с упрощенным датасетом
2) была задумка в одном файле для набора алгоритмов получить дефолтные результаты для датасета, потом провести optuna-оптимизацию и затем перезапустить алгоритмы на новых "лучших" параметрах. К сожалению, ограничения по памяти, частые (на начальном этапе) отказы алгоритмов оптимизации (из-за несостыковки гиперпараметров, например) привели к разделенной модели. А именно: файлы вида ds_4_2_* - каждый посвящен одному алгоритму и сохраняет результат своей работы для отчета в папке /data/pick/*.
3) Итоговый отчет в файле ds_4_3_report.ipynb. Вычитывает результаты работы алгоритмов из /data/pick/*, сортирует по метрике, строит графики, выводит статистику по лучшему алгоритму. Можно начинать с него
